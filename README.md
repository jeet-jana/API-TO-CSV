# API_TO_CSV

A simple Python project that fetches data from an API in JSON format and converts it into a CSV file.

## Technologies
- Python
- Requests
- Pandas
- JSON
- CSV

## Installation

```bash
pip install requests pandas
```

## Usage

Run the Python file:

```bash
python main.py
```

## Purpose

This project helps collect data from APIs and prepare datasets for data analysis and machine learning.
